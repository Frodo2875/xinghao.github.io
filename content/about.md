你好，我是 **Xinghao**，欢迎来到我的个人博客。

这里用来记录技术学习、项目实践，以及日常的观察与思考。把问题写清楚，把过程留下来，也让下一次探索有迹可循。

## 你可以在这里找到

- **技术笔记**：概念梳理、代码示例与问题排查。
- **学习记录**：数学推导、课程笔记与阅读整理。
- **项目实践**：从一个想法到具体实现的过程。

## 关于这个小站

使用 Hugo 构建，基于 Blowfish 主题，托管于 GitHub Pages。支持文章搜索、明暗模式、代码复制与数学公式。

这是博客的初始版本。更多文章和个人介绍，会随着写作慢慢补齐。
